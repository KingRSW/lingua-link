## ✨ 功能

- **长文本翻译**：单次可译 5000 字（免费版 500 字）
- **AI 润色（PRO）**：地道 / 商务 / 学术 / 简洁 四种语气一键润色
- **翻译历史**：自动保存最近 50 条
- **云端同步**：多设备共享翻译记录
- **无广告** · 高峰期**优先通道**
