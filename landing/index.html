用爱思助手给 iPhone 装 IPA

爱思助手是免费的苹果设备管理工具。我们的 iOS 包是未签名 IPA，用你自己的免费 Apple ID在爱思助手里「签名 → 安装」即可，无需越狱、无需付费账号，7 天有效，到期重签。

⬇ 下载爱思助手（官方）
连接设备电脑安装爱思助手，iPhone 连上并「信任此电脑」。
Apple ID 签名工具箱 → IPA 签名 → 选「Apple ID 签名」，导入 Lingua Link 的 IPA，用你的 Apple ID 登录后签名。
安装并信任安装到手机；设置 → 通用 → VPN 与设备管理 信任描述文件，即可打开使用。
